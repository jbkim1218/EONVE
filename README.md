# EONVE · 이온브

**Beautiful by Design. Effortless by Nature.**

## 쇼핑몰 소개

EONVE는 차분한 뉴트럴 컬러와 자연스러운 실루엣을 중심으로 만든 남녀 의류 쇼핑몰 포트폴리오입니다. 시즌 화보와 상품 착용컷을 활용한 디자인으로, PC와 모바일에서 상품 탐색부터 모의 주문까지 경험할 수 있습니다.

## 주요 기능

- **상품 탐색** — 여성·남성 컬렉션, 신상품, 에디터 추천 상품.
- **검색과 필터** — 상품 검색, 카테고리·색상·사이즈·가격 필터, 가격 정렬.
- **상품 상세** — 착용 이미지와 확대 보기, 색상·사이즈 선택, 소재 안내.
- **위시리스트** — 하트로 상품 추가·해제, 전용 목록, 새로고침 후 유지.
- **장바구니** — 담기 후 목록으로 이동, 옵션별 상품 구분, 수량 변경·삭제, 합계 확인.
- **바로 구매** — 선택한 상품의 주문 확인 후 모의 주문 확정. 기존 장바구니는 유지.
- **플로팅 메뉴** — 고객 페이지에서 맨 위·장바구니·위시리스트로 빠르게 이동.
- **관리자 데모** — 상품·카테고리 관리, 메인 배너와 추천 상품 편집.
- **반응형 화면** — PC·태블릿·모바일에 맞춘 레이아웃과 모바일 하단 구매 버튼.

## 사용 기술

| 분야 | 기술 |
| --- | --- |
| 프레임워크 | Next.js App Router, React |
| 언어 | TypeScript |
| 스타일 | Tailwind CSS, CSS |
| 상태 관리 | Zustand, localStorage |
| 브라우저 데이터 저장 | Dexie, IndexedDB |
| 폼 및 입력 검증 | React Hook Form, Zod |
| UI 및 아이콘 | Base UI, Lucide React |
| 테스트 | Vitest, React Testing Library, Playwright |
| 코드 품질 및 CI 설정 | ESLint, Prettier, GitHub Actions |

> 실제 결제·판매·배송이 발생하지 않는 데모입니다. 상품과 가격은 가상 데이터이며, 관리자 변경 사항과 장바구니·위시리스트는 각 브라우저에 저장됩니다. 관리자 화면은 인증 기능이 없는 체험용 화면입니다.
